### 2. AOE Damage Implementation ✅

**Problem**: `FeatureEffectAreaDamage` was defined in code and evaluated by AI, but not implemented in `ResolveEffect()`. Would throw "unknown effect category" errors.

**Solution**: Implemented multi-target damage resolution

**Implementation**:
- Added `resolveAreaDamage()` function (feature_resolver.go:200-254)
- Rolls damage once, applies to all enemies of actor
- Respects damage type (physical/magic), armor, resistance/immunity
- Triggers on_damage_taken for each target hit
- Added to effect type dropdowns in both player and adversary forms

**Test Created**: `cmd/aoe-test/main.go`
- Wizard with "Fireball" (3d6+2 magic AOE)
- 3 Goblins as targets
- Result: All 3 goblins damaged correctly by each Fireball cast ✓
- Multiple runs confirmed consistency ✓

**Files Modified**:
- `internal/engine/feature_resolver.go:61-62,200-254` - AOE resolution
- `ui/components/domain_ability_form.go:381` - Added to dropdown
- `ui/components/adversary_feature_form.go:227,387` - Added to dropdown
